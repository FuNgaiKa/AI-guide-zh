# AI Guide 中文实践手册

一份面向中文开发者的 AI 工具实践指南，记录模型选择、Codex 工作流、提示词与自动化教程。

这里不追求罗列所有模型和榜单，而是把公开资料与真实使用体验放在一起，回答更实际的问题：什么任务该用什么模型、何时值得升级，以及如何减少等待、额度浪费和返工。

>
> 内容会随模型、产品和个人实践继续修订；涉及价格或产品能力时，请以链接中的官方页面为准。

## 内容口径

仓库中的结论分为三类：

1. **官方信息**：模型定位、能力和 API 价格，附官方链接和核对日期。
2. **公开评测**：注明基准、版本、筛选条件与局限，不把不同测试体系的分数直接相加。
3. **个人体验**：明确标注为主观观察，并按日期保留历史变化。

公开评测不等于真实项目表现，API token 价格也不等于 ChatGPT 或 Codex 订阅中的额度消耗。
